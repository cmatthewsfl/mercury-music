# Mercury Music

Cindy + Mercury's mobile-first music launcher.

## Live site
GitHub Pages publishes this repository as a lightweight home-screen-friendly playlist portal.

## Structure
- `index.html` — interface
- `playlists.js` — playlist catalog
- `manifest.webmanifest` — install metadata
- `sw.js` — lightweight offline shell cache
- `icon.svg` — Mercury launcher icon

To add a playlist, add one object to `playlists.js`.
